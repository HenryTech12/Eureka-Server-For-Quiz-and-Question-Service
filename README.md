# Eureka Server - Microservices Project

This repository contains the Eureka Server component of a microservices-based Java application. The Eureka Server acts as a service registry, allowing microservices to discover and communicate with each other.

## Project Structure

This is one of three repositories for the project:
- **eureka-server** (this repository) - Service registry using Netflix Eureka.
- **quiz-service** - One of the microservices that registers with Eureka.
- **question-service** - Another microservice that registers with Eureka.

## Technologies Used

- Java 17+  
- Spring Boot  
- Spring Cloud Netflix Eureka  
- Maven
